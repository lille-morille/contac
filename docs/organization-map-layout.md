# Organization map layout

The organization map uses [AntV G6](https://g6.antv.antgroup.com/en/manual/introduction) for pan and zoom. Each domain is a section containing organization cards; each organization card contains a vertical list of its contacts. The sections are packed outward in two dimensions with at least 80px between their full rectangles. Cards use the existing application colors and components. Duplicate and deleted contacts are hidden. Contact cards and organization titles open their existing details with one click.

An organization belongs to at most one domain. Migration `0051_single_company_domain.sql` removes extra historical links and adds a unique index on `company_domains.company_id`. The link table has no creation timestamp, so the lowest domain UUID is retained. The graph and UI use the same rule when reading historical multi-domain links in unmigrated environments. The organization popup offers one domain choice or no domain. AI suggestions, MCP tools, and API updates also accept at most one domain.

Every contact is visible within its organization card. Each map card shows up to two lines of description; clicking it opens the full contact text. Longer organization and contact names wrap within taller cards. Cards do not scroll internally. The graph pans with two-finger trackpad gestures, drag, and touch. Trackpad pinch or Ctrl+wheel zooms at the pointer. Keyboard focus brings a card into view; pointer clicks leave the viewport in place. The fit and zoom controls remain available, and the minimum zoom is 5%. The initial readable zoom is 85% on desktop and 70% on narrow screens; a domain taller than the viewport opens at its heading.

Contact cards reuse the Kanban status icon and assignee avatar around the name, with the short description below. The avatar falls back to the unassigned icon when no team member is assigned. The map omits Kanban stikkord.

Clicking a domain heading opens an anchored popup with its description editor and conversation summary action. Domain clicks keep the full overview in place; old `mapDomain` links open the overview. Organization focus links continue to work.

The local preview can run against production Supabase without storing production credentials in the repository. The Vite proxy targets are set by `CONTAC_DEV_SUPABASE_TARGET` and `CONTAC_DEV_API_TARGET`; their defaults remain the local services. The local API needs its own server-side production connection settings. Set `DB_POOL_MAX=2` for this preview to stay within the production pooler's session limit.

## Verification

The graph model tests cover historical multi-domain normalization, organization selection, duplicate contact exclusion, compact descriptions, complete contact lists, and rectangle clearance for a synthetic team-sized map. The local Chromium preview was checked at 756 × 1137, 1440 × 900, and 2478 × 1862 with 71 organizations, 13 domains, and 140 contacts matching the live team's measured density. All cards rendered, no sections overlapped or scrolled internally, and eight repeated loads aligned the largest domain heading. Trackpad-style pan stayed in place after two seconds, pinch-style zoom changed scale, and one click opened the organization card. The user reviewed the overview and approved the main-branch push on 2026-10-08. Migration 0051 was applied to Contac Production on 2026-10-08: 13 extra links were removed from 11 organizations, leaving 84 links, no organizations with multiple domains, and a valid unique index.
