# Grayscale page wireframes

These seven **built-in imagegen** mockups are layout sketches for pages and states that did not have a supplied Linear screenshot. They intentionally use grey skeleton content and do not define typography, colors, spacing tokens, component behavior, or final copy. The five files in `../spec/` are authoritative when a generated label, date, state, or placeholder differs from a requirement. The supplied Linear screenshots remain the reference for the board and contact detail layout.

| Page | Image | Generation prompt focus |
| --- | --- | --- |
| Unified inbox | [inbox.png](inbox.png) | Desktop, Norwegian title and inbox filters, reminder detail, pending email and access-request rows |
| Check-in session | [checkin-session.png](checkin-session.png) | Activity selection, backdated activity note, AI-blocked activity, saved recap panel |
| Semantic search | [search.png](search.png) | Search field, filters, relevant passage highlights, contact/activity preview |
| Team library | [library.png](library.png) | Quote snapshots, source links, edited/deleted source indicators |
| Organization map | [organization-map.png](organization-map.png) | Top-to-bottom graph with separate direct, color-matched links from each domain to one organization |
| LOI editor | [loi-editor.png](loi-editor.png) | Previous sent LOI's company and sender, preview-before-copy action, variables, sections and versions |
| Previous LOI preview | [loi-previous-preview.png](loi-previous-preview.png) | PDF preview overlay before choosing whether to copy the previous LOI |

Most prompts requested a single 16:9 desktop UI wireframe, grayscale only, with simple Norwegian labels, no brand styling, no photography, and no watermark. The organization map adds restrained domain colors at the user's request; all other elements remain skeletal. The discarded generations are not part of this workspace.
